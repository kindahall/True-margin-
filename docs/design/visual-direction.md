# Visual Direction

## Source Screens

The product screens in `docs/design/reference/` define the UI direction. They are reference screenshots for implementation, not the final product itself.

- `overview.png`
- `product-detail.png`
- `alerts.png`
- `integrations-costs.png`
- `ui-board.png`

## Language

The final app UI must be English. The light reference screens already use English and should drive product copy. The dark board is useful for route coverage and density only; do not reuse non-English labels from it.

## Product Feel

The app should feel like a precise B2B SaaS tool:

- Calm white workspace.
- Deep navy navigation.
- Compact cards and tables.
- Clear product thumbnails.
- Blue primary actions.
- Green profit, orange warning, red loss.
- Exact vs estimated cost badges.
- No marketing-style hero page inside the app.

## Core Screens

## UI Rule

Every visible action must be real or deliberately omitted. The final product cannot be static screenshots.
