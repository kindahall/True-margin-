# Marketplace Listing Copy

## Short Description

True Margin Tracker shows real product margin after product cost, shipping, payment fees, ad spend, refunds, and returns.

## Long Description

True Margin Tracker is a focused profitability tool for small and growing e-commerce stores. Connect Shopify, WooCommerce, or WordPress catalog data, add product costs, import CSV cost files, and see which products are actually profitable after every variable cost.

The app stays empty until real store data is connected. It does not ship with sample products, fake revenue, or invented margin numbers.

## Key Benefits

- Real margin per product.
- WooCommerce and WordPress installable plugins.
- Owner-site WooCommerce license bridge.
- Shopify OAuth install flow.
- Manual cost editing and CSV imports.
- Payment, shipping, return, and ad-cost inputs.
- License activation for owner-site sales.
- Price Scout product URL analysis with optional real market-price provider.
