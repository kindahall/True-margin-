# Privacy Policy

Last updated: May 24, 2026

True Margin Tracker helps merchants calculate product profitability from connected store and catalog data.

## Data We Process

When a merchant connects Shopify, WooCommerce, WordPress, or a supported checkout and payment provider, the app may process:

- Store name, store URL, and platform connection status.
- Product titles, SKUs, catalog URLs, product prices, product costs, packaging costs, and return-cost assumptions.
- Order IDs, order dates, line items, quantities, order totals, shipping totals, refunds, and currencies.
- Payment fee and advertising cost data when those integrations are connected.
- Account email, workspace name, license status, team members, and API key metadata.

The WordPress and WooCommerce plugins send data only after an administrator saves an API URL and connection token.

## How We Use Data

We use connected data to:

- Calculate real product margin.
- Show profitability dashboards, product reports, order reports, and alerts.
- Validate plugin and store connections.
- Activate and manage licenses.
- Provide support and troubleshoot merchant-reported issues.

## What We Do Not Do

- We do not create sample revenue, fake products, or invented order data.
- We do not sell merchant data.
- We do not use merchant data for unrelated advertising.
- We do not load third-party executable code inside the WordPress plugins.

## Data Sharing

Data can be shared with service providers only when needed to run the product, such as hosting, databases, payment processing, email delivery, monitoring, and support tools. Each provider should be configured under a suitable data-processing agreement before public launch.

## Data Retention

Workspace data is retained while the merchant account or license is active. Merchants can request deletion of account, store connection, product, and order data by contacting support.

## Security

The API supports authentication, bearer sessions, signed plugin webhooks, encrypted plugin secrets at rest, Stripe webhook signature verification, and rate limits for public endpoints.
